# Coinage

一个纯前端造字工作台。导入图片，提取笔画中心线，编辑共享节点与局部宽度，导出真正的 SVG 路径。采用 React、TypeScript 和 Vite，无需后端或外部 API。

## 启动

Node.js 20.19+（20.x）或 22.12+。

```bash
npm install
npm run dev
```

打开终端中显示的本地地址，默认是 http://localhost:5173。首次打开包含三个可编辑示例字符；手稿名称旁的菜单可以导入附带的原始示例图片。

## 常用命令

- `npm run dev`：启动开发服务，支持热更新。
- `npm run build`：检查 TypeScript 类型并打包到 `dist/`。
- `npm run preview`：本地预览打包结果，需先运行构建。
- `npm test`：运行骨架提取、共享节点、闭环、宽度、曲线、SVG 导出与数据校验测试。

## 使用

1. 点击「导入图片」或把 PNG、JPG、WebP 拖到画布。预览中调整前景颜色、识别阈值、路径简化与去噪；彩色字形可勾选「只提取彩色笔画」过滤灰度背景。
2. 选择节点后拖动位置。拖动节点旁的加号，或按住 Alt 拖动节点，即可创建连接的新笔画。双击笔画插入节点。
3. 在属性面板调整当前节点宽度、转角类型和曲线控制柄。不选节点、只选笔画时，宽度与转角设置作用于整条笔画。平滑节点的两侧控制柄方向联动、长度独立；对称节点的控制柄等长。
4. 用钢笔连续点击绘制一条笔画，点击现有节点可连接或闭合路径；Esc 结束。交汇节点由多条笔画共享，移动时保持连接。靠近另一个节点后可用「连接邻近节点」合并。
5. 支持锁定/隐藏笔画、复制、翻转、旋转、删除、撤销/重做、原图叠加、网格、标尺、缩放和平移。
6. 「导出 SVG」输出透明背景、可缩放的填充路径；下拉菜单还能导出 1280 × 1280 透明 PNG 或保留全部编辑数据的 JSON 手稿。

| ------------------------- | ------------------------ |

## 数据与转换

数据自动保存在当前浏览器的 localStorage；刷新后恢复。清理浏览器数据会清除本地手稿，存储不足时界面会提示导出。可用 JSON 手稿备份、转移，并通过手稿菜单重新打开。撤销记录保留最近 60 步，仅在当前会话有效。

图片处理完全在本机进行：最长边缩放至 360 像素进行前景识别，去除小连通区域，通过 Zhang–Suen 细化提取中心线，以距离场估计宽度，再将图结构简化为可编辑路径。转换在 Web Worker 中执行。导出根据这些路径、控制柄和宽度重建闭合轮廓，不嵌入原始位图。

自动提取是中心线重建，不是逐像素轮廓复刻；尖锐交汇、复杂纹理、书法飞白和细小笔画可能需要调整阈值或手动修整。建议使用清晰、前景与背景对比明显的图片。目前导出独立 SVG 字形，不生成 TTF/OTF 字体文件。

## 代码结构

- `src/app/`：工作台组装、字符集、导入导出与快捷键。
- `src/features/editor/`：画布交互、属性面板与字形预览。
- `src/features/tracing/`：图片导入、前景分离、骨架提取与转换 Worker。
- `src/features/project/`：手稿状态、撤销重做与本地保存。
- `src/core/`：共享数据结构、几何算法、SVG 输出与数据校验。
- `src/shared/`：通用控件、图标与文件工具。
- `src/styles/`：全局样式与响应式布局。
- `src/static/`：文字与笔锋原始素材。
- `tests/core.test.ts`：算法与数据完整性回归测试。

完整目录说明和开发约定见 [AGENTS.md](AGENTS.md)。
