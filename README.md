# Coinage

本地造字工具：从图片提取笔画，编辑字形，再导出 SVG 或透明 PNG。图片处理与手稿保存都在本机完成。

## 开始使用

Windows 便携包解压后，双击 `双击运行.bat`，浏览器会自动打开工作台，无需安装 Node。使用期间保持命令窗口开启，关闭窗口即可停止服务。

## 主要功能

- **字库**：输入句子后展开预览并自动换行，按对应汉语匹配，较长词语优先，缺字显示加深底色和边框的空字格；清空输入收起预览。造句内容自动保存在当前浏览器，下次进入时恢复，清空后也会记住。输入框右侧的字形大小按钮仅显示当前大、中、小，悬停展开菜单切换；相邻图标按钮切换特效和字格；默认显示特效和字格，字形默认为小（原尺寸）。关闭字格后仅隐藏匹配字符的字格，缺字仍保留提示；设置保存在当前浏览器。点击字形进入造字，也可直接右键编辑基本信息、复制或删除，与造字共用菜单和操作。
- **导航**：左侧切换字库、造字与样式。样式页提供当前字符预览和外观配置，可统一设置全部字符的笔画颜色或选择预设色，修改自动保存。
- **样式特效**：样式页提供不超过 400 px 的字符预览；“燃烧”以单次字形绘制搭配连续焰根、卷曲火舌和渐隐焰尖，辅以明亮火星，支持焰橙、幽蓝、碧焰、灰黑配色及火势、速度、方向调整；灰黑采用炭黑暗部、冷灰火舌和幽灰焰尖。火焰只从朝向燃烧方向的外缘供燃，提高纹理精度以柔化背向边缘。鼠标移动会沿路径留下不可见气流，带动附近火舌和细纹；气流随时间漂移、扩散并消散，停下或反向后保留短暂尾流，影响按平方距离柔和衰减，每团气流的作用半径不超过单个字形渲染宽度的一半；在预览外移动也可带动附近火焰。扰动幅度为初版气流效果的三倍，强度可在 0–100% 调整，默认 50%，0% 关闭扰动。“符文”保留字形内部的呼吸闪烁、流动纹理和扫光，不显示外围法阵，支持光色、辉光强度、流动速度和方向，并提供冰蓝秘文、紫晶奥术、鎏金圣印、古玉灵纹四个预设。配置栏加宽以便桌面上一行放下四个预设。冰蓝使用半透明蓝色深层、放大的不规则晶面折射、疏密变化的裂隙与霜花；鎏金使用深金暗部、镜面反射带、细拉丝和边缘高光，反光随鼠标透视变化。古玉以青绿底色、固定云絮沁色、乳白透光和柔和边缘高光呈现温润玉质，保留流光与点击交互。符文会随鼠标位置轻微透视倾斜，点击实际笔画时从点击位置扩散一圈光晕，扫过整个字符；亮带保留原有粗细，并叠加柔和晕染与轮廓散光，点击光晕整体不透明度为此前的一半；透明区域点击无效，可连续点击。光晕粗细可在 10–100% 调整，默认 50%，为原始光晕宽度的一半。颜色和特效统一保存在全局样式中，对全部现有及新增字符生效；切换字符不改变配置，切换特效保留各自参数。预览保持透明背景，两个特效的方向支持 0–360° 调整，0° 朝上、顺时针旋转。特效只在样式展示和字库造句预览中生效；造字画布、字符缩略列表及 SVG/PNG 导出保持原字形。采用本地 GPU 渲染，无需联网；重复字形共享纹理并独立响应点击，供燃场仅在轮廓或方向变化时生成；燃烧和符文各自的交互与着色逻辑按特效分文件维护。交互状态不写入手稿，减少动画偏好下显示静态效果，不支持 WebGL 时保留普通字形预览。
- **字符集**：新建空白字符或导入图片后，列表自动滚动到新增字符。支持编辑基本信息、复制和删除。删除字符需二次确认且无法撤销。对应汉语作为标题及造句匹配关键字，描述作为浅灰色副标题，两项均可留空。
- **图片描摹**：支持 PNG、JPG、WebP，也可直接拖入画布。预览与编辑画布共用格线，叠加原图以便定位；图片按长边适配字格，保留长宽比，提取有效笔迹后保持大小居中；字形缩放默认 100%，可在 10–200% 内调整，仅改变字形布局，不改变笔画粗细，X/Y 偏移各用一条 -100–100 px 滑条。笔画粗细默认 24 px，可在 1–200 px 内调整；缩放、粗细与偏移实时更新，无需重新识别图片，缩放与偏移受节点边界限制。全部导入参数保存在本地服务的 `data/import-settings.json`，下次导入自动使用上次配置；配置区的“恢复默认”可一键重置全部导入参数并保存，保存失败可重试。
- **文件名提取信息**：图片预览框下方可输入模板，实时展示将导入的对应汉语和描述。`{name}` 表示汉语，`{desc}` 表示描述，默认尽量少取；占位符内加 `*`（如 `{name*}`、`{desc*}`）表示尽量多取，多个字段按从左到右的顺序匹配。其他文字或符号原样匹配，每个字段最多一次且需有分隔符。默认 `{desc*}_{name}` 从最后一个下划线拆分：`狼族语_0002s_0038_朋友.png` 得到汉语“朋友”、描述“狼族语_0002s_0038”；`{desc}_{name}` 则从第一个下划线拆分，`{name*}_{desc}` 可让汉语尽量多取。匹配时忽略图片扩展名；使用 `{name}` 或留空可直接使用完整文件名。模板无效或未匹配时提示并使用去掉图片扩展名的文件名，描述留空。模板随导入配置保存，修改模板无需重新识别图片。
- **笔画与节点**：切换列表查看，拖动节点、调整粗细和曲线，支持多选、连接、拆分、锁定及隐藏。选择模式下从画布空白处拖动可框选节点，按住 Shift、Ctrl 或 ⌘ 可追加框选；跳过隐藏及锁定节点，Esc 取消框选。选中节点后，在画布上向上滚轮加粗、向下滚轮变细，每次滚动调整 1 px；连续滚动只记一次撤销，Ctrl/⌘ + 滚轮缩放画布。在选择工具下右键笔画的一条边，选择“插入中点”在该边中点新增节点，保留共享节点连接、原有曲线和笔锋轮廓，支持撤销重做。
- **拖动与复制**：节点和控制柄拖回原位时恢复原有轮廓，不新增历史；复制笔画靠近画布边界时整体限制偏移，保持笔画形状。
- **笔锋与画布**：统一调整起收笔形态，提供原图叠加、网格、缩放、平移及撤销重做。撤销重做仅针对造字编辑，字符的新建、导入、基本信息编辑、复制和删除不进入操作历史。
- **导出**：未选中节点或笔画时，在右侧属性栏底部导出 SVG，或通过下拉菜单导出透明 PNG。目前不生成 TTF/OTF 字体。

## 保存与备份

编辑后约一秒自动保存，`Ctrl+S` 可立即保存；重新打开会恢复手稿。备份或迁移前先关闭服务，再复制程序目录中的 `data/`；升级时保留该目录。保存失败时，可按界面提示导出应急副本。

## 从源码运行

需安装 Node.js 20.19+（20.x）或 22.12+，以及 pnpm。

```bash
pnpm install
pnpm run dev
```

开发服务默认地址为 `http://127.0.0.1:47832`，端口被占用时会自动尝试后续端口，以终端显示的本地地址为准。

如需生成 Windows 便携包：

```bash
pnpm run build
```

打包后分发项目根目录的 `Coinage v<版本号>.zip` 即可。

## 代码格式

使用项目内安装的 Prettier，配置见 `.prettierrc.json`。每轮修改后只格式化本次改动的文件：

```bash
pnpm exec prettier --write <文件路径列表>
```

`pnpm run format` 格式化全项目，`pnpm run format:check` 检查全项目格式。构建产物、手稿、原始素材及锁文件通过 `.prettierignore` 排除。

## 公共界面组件

`src/shared/components` 提供 `Modal`、`Menu`、`Button` 和 `ToastProvider` / `useToast`。弹窗统一使用原生 dialog 管理焦点与背景交互；菜单支持方向键、Home / End、Esc 和 Tab，并隔离背景编辑快捷键。Ctrl+S 在弹窗及菜单内仍可保存。提示区分成功、错误和普通消息，同文案重复触发会重新计时；业务表单与编辑命令保留在各 feature。导航、列表、属性、笔锋及启动失败重试按钮也复用公共按钮，保留各自外观。弹层内释放空格会解除临时平移，中文输入法取消组合输入不会关闭弹窗。

文本输入使用 `Input`，数值输入使用 `NumberInput` / `NumberField`，分段选择使用 `SegmentedControl`。数值支持即时更新或失焦 / Enter 提交草稿，Escape 取消；分段选择保留原有按钮和 Tab 操作，并支持方向键与 Home / End。业务取值、边界和预览内容由调用方提供，手稿输入通过 editor 的事务适配器合并连续编辑历史，公共控件不依赖手稿状态。文件、颜色和单处使用的复选输入保留原生控件。
