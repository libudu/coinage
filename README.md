# Coinage

本地造字工具：从图片提取笔画，编辑字形，再导出 SVG 或透明 PNG。图片处理与手稿保存都在本机完成。

## 开始使用

Windows 便携包解压后，双击 `双击运行.bat`，浏览器会自动打开工作台，无需安装 Node。使用期间保持命令窗口开启，关闭窗口即可停止服务。

## 主要功能

- **字库**：输入句子后展开预览并自动换行，按对应汉语匹配，较长词语优先，缺字显示加深底色和边框的空字格；清空输入收起预览。点击字形进入造字。
- **导航**：左侧切换字库与造字，特效暂未开放。
- **字符集**：新建空白字符或导入图片，支持编辑基本信息、复制和删除。对应汉语作为标题及造句匹配关键字，描述作为浅灰色副标题，两项均可留空。
- **图片描摹**：支持 PNG、JPG、WebP，可调整识别参数并预览，也可直接拖入画布。
- **笔画与节点**：切换列表查看，拖动节点、调整粗细和曲线，支持多选、连接、拆分、锁定及隐藏。
- **笔锋与画布**：统一调整起收笔形态，提供原图叠加、网格、缩放、平移及撤销重做。
- **导出**：未选中节点或笔画时，在右侧属性栏底部导出 SVG，或通过下拉菜单导出透明 PNG。目前不生成 TTF/OTF 字体。

## 保存与备份

编辑后约三秒自动保存，`Ctrl+S` 可立即保存；重新打开会恢复手稿。备份或迁移前先关闭服务，再复制程序目录中的 `data/`；升级时保留该目录。保存失败时，可按界面提示导出应急副本。

## 从源码运行

需安装 Node.js 20.19+（20.x）或 22.12+，以及 pnpm。

```bash
pnpm install
pnpm run dev
```

打开终端显示的本地地址即可使用。

如需生成 Windows 便携包：

```bash
pnpm run build
```

打包后分发项目根目录的 `Coinage v<版本号>.zip` 即可。
